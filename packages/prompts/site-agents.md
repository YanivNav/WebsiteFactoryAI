# Generated Wix site

This repository is the source for one Wix-managed Headless website generated by Website Factory.

- Preserve `wix.config.json`, Wix's Astro integration, authentication setup, and generated scripts.
- Use Astro components and the existing project conventions. Prefer reusable components over
  duplicated page markup.
- Keep Astro templates conventionally formatted. Never compress whole sections onto one line.
- Treat `.factory/context/` as read-only generation input. Never import it into the shipped site.
- Implement real Wix business-solution integrations where the approved specification requires
  Stores, Bookings, Events, Blog, Members, Forms, or Pricing Plans.
- CMS-backed entities must query the verified collection IDs in `.factory/context/site.json` with
  `@wix/wix-data-items-sdk`. Never replace them with arrays under `src/data/`.
- Never hotlink Stitch or `googleusercontent.com` assets. Use the Wix Media replacements supplied
  in `.factory/context/site.json`.
- Every visible control must work. Follow the specification's visitor workflows end to end. Custom
  inputs are not automatically Wix Forms; use the Wix API matching each declared action.
- Do not publish, release, push, rewrite Git history, or change remotes. The factory owns those
  operations.
- Run focused checks when practical, but the factory performs the final Wix build and repair loop.
- Never commit secrets or edit generated Wix credential values.
